# PIT · Postplanning

Dagplanning voor Instagram (stories en feedposts, met tijden, captions en Meta-regels) als installeerbare web-app, met een fotostudio die je foto automatisch in de blauw/witte huisstijl zet (story 1080x1920, feed 1080x1350). Opent op vandaag, werkt offline, foto's en vinkjes blijven op je telefoon.

Installeren: open de site in Safari, tik op Deel en kies "Zet op beginscherm".
